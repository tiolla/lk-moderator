# Кабинет врача-модератора

Рабочее место врача-модератора и координатора ФИЦ Биомед: проверка заявок участников клинических исследований. Прототип написан на React.

## Что умеет

- **Проверка.** Очередь по визитам протокола, отложенные заявки, общий прогресс, поиск, клавиши.
- **Карточка заявки.** Отбор с автопроверкой критериев, документ и окно чтения, замечания к полям, анкета визита по разделам, сравнение с прошлым визитом, решения с отменой в течение 10 секунд, история решений.
- **Две роли.** Координатор смотрит заявку первым и передаёт врачу или возвращает участнику. В исследовании без координатора врач проверяет сам.
- **Участники.** Таблица с сортировкой и страницами, родственные группы, граф семьи, выгрузка в CSV.
- **Исследования.** Руководитель исследования назначает и снимает координаторов и врачей.
- **Сводка.** Заглушка с описанием будущего раздела.
- **Демо-панель** (кнопка с жучком справа внизу). Смена пользователя, события со стороны участника, наполнение демо-данными.

## Запуск

Нужен Node.js 20.19 или 22.12 и новее.

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Сборка для сайта — `npm run build`, посмотреть её можно через `npm run preview`. Без демо-панели: `VITE_DEMO=off npm run build`.

Адрес открывает нужное состояние сразу:

| Адрес | Что откроется |
|---|---|
| `?user=orlova` или `?role=coord` | вход координатором |
| `?user=petrov` | вход врачом, который руководит «Ожирением» и «Щитовидной» |
| `?app=ЗАЯВ-2026-0417` | карточка заявки на отборе |
| `?app=ЗАЯВ-2026-0402&tab=anketa&sub=3` | анкета, раздел 3 |

## Стек

React 19, Vite 8, zustand 5 с immer, JavaScript, ESLint. Код разложен по слоям Feature-Sliced Design.

## Данные

Все данные придуманы. Демо-набор из 97 заявок по пяти исследованиям собирает генератор с постоянным зерном, поэтому при каждом открытии набор одинаковый. Сервера нет: решения, замечания и назначения сохраняются в браузере. Исходный набор возвращает кнопка «Сбросить демо-данные» в демо-панели.
